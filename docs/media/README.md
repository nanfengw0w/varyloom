# Live effect recordings

These GIFs are recordings of the live showcase using the npm release `varyloom@0.1.0`, captured on 2026-09-24. They show Particle Shift, Meteor Wake, and Memory Mosaic with three-second transitions. They are preview thumbnails; use the linked playground for full-resolution interactive rendering.

Photograph credits and source URLs: [website/ASSETS.md](../../website/ASSETS.md) and [sources.json](../../website/public/images/sources.json).

Particle Shift and Meteor Wake require WebGPU. No fallback rendering was used for these recordings.
